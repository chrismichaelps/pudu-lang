# Website Document View

Renders Code of Conduct, Contributing, Security, Community, Privacy, and Brand from their repository Markdown. Each page opens with the shared compact banner and retains a source link before the document body. A curated complete sentence provides the banner lead, because source Markdown summaries can be wrapped across lines.

## Grill Log

- **Q:** Copy the policies into the view? **A:** No; render the source documents. _Rationale:_ the repository document remains the one text maintainers edit and review.

Resolved Grill Log: preserve one title and source link on every page; the banner contains only the page label, title, and summary.
