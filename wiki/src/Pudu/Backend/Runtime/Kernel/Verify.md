# Native Signature Kernels

Export the family's runtime parts and their prerequisites.

RSASSA-PKCS1-v1_5 over SHA-256 and ECDSA over P-256 with SHA-256, as the interpreter's library answers them. The curve arithmetic is the same affine addition and doubling, with the same equality tests on unreduced inputs, so a point off the curve answers alike.

Follow the reference step by step rather than a faster coordinate system, whose results differ for invalid keys.
