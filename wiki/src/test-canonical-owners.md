# Canonical Owner Gate

`node test/canonical-owners.mjs <optimized-compiler>` runs the CLI against isolated modules whose same-named record declarations implement
one trait. Both evaluator modes, both import orders, direct/generic/retained/aliased and explicit
methods must retain defining-module captures. Printed record labels and checked patterns remain
stable. Folded record constants dispatch like fresh constructions. Cache-off, cold and warm
runs agree, and warm product inode identities remain stable.
Wrong-type fixtures retain positioned static diagnostics. Native record
factories must compare equal to source reconstructions of their own fields.
