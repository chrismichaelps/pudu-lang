# Lsp Method Definition Spec

## Coverage

One program exercises every owner a call can have: a value's impl method (`square.area()`), a
static method through its type (`Square.unit()`), a method generated by a derive in the same file
(`point.named()` opens the derive's `fn named`), a library derive's method (`square.equals(…)` opens
`Std/Order.pudu`), a call through a type parameter by value and statically (`shape.area()`,
`A.unit()`, both at the trait members), and an inherited default (`square.label()` at the trait).
