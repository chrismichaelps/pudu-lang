# Backend Service Programs

Export hostServicePrograms: stream endpoints, gzip and bare streams, child
programs, time rendering and reading with stop requests, and secured
connections. Each is one program with the interpreter's output as its
expectation.

## Resolved Grill Log

No expectation holds a descriptor number, a port, a token another thread may
take first, a compressed byte run, or a library's own reason: a refusal that carries one is reduced to its kind inside
the program. Reads that depend on arrival are gathered to the end, and a wait
that must run out is bounded by a short budget. Secured connections are
checked without leaving the machine: closed tokens, spent budgets, a listener
that never answers and one that hangs up mid-handshake. A handshake that
succeeds needs a certificate the machine trusts, so it is evidence gathered
by hand against public hosts and recorded in [[Native Remaining Emission
Delivery]], not a property. Programs here are not counted for allocations:
the counted harness links no system library.

The time-reading cases check both signs beyond the signed millisecond boundary, the largest
admitted magnitude, an invalid date, a large calendar date overridden by epoch seconds,
and offset adjustment with ties-to-even rounding. At the first instant outside the
carrier, require either the interpreter's exact wider value or the documented native
refusal. A truncated or saturated value cannot satisfy either outcome.

A parse-and-format program checks the maximum positive magnitude, large negative
instants, the minimum signed millisecond and a negative subsecond. Both the
civil time and floor-rounded epoch seconds must match the interpreter.

The epoch-seconds probe checks both carrier limits, including the negative second
whose fraction returns it to range, and the next rounded millisecond beyond
each limit.

Resolved Grill Log: standard-input fixtures carry the exact input bytes and
expected output, including growth past the initial buffer, embedded zero,
multibyte text, truncated encoding, and repeated refusal or end of input.
The native conformance harness supplies each byte stream to both engines.
