# Backend Output Programs

Export outputSuccessPrograms (stdout with explicit answers),
outputStreamPrograms (stdout and stderr answers), and outputRefusalPrograms
(accepted operations reporting runtime diagnostics). Exercise stored and
nested Result values, matches, propagation, arguments, loop breaks, returns,
equality and entry reporting. Partial writes include Unicode and NUL.

## Resolved Grill Log

Success cases lock independent byte outputs in addition to differential
comparison. Runtime failures preserve prior output and exact source spans.
The same corpus participates in counted lifetime checks where outputs are
healthy. No unsupported refusal is treated as successful native coverage.
