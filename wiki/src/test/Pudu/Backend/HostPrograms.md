# Backend Host Programs

Export hostSuccessPrograms, hostCountedPrograms, hostLibraryPrograms and
hostRefusalPrograms: the
float and lane kernels, clocks and surroundings, files and handles, cells,
locks, channels and threads, tasks and scopes, and tables of functions.
Counted programs also run under the counted-allocation harness; refusal
programs pin failures inside tasks, scopes and kernels with their spans.

## Resolved Grill Log

Every expectation is what the interpreter prints for the same program.
Programs that read the clock or the machine assert relations, never values.
A machine's own answer cannot reach an expectation: the temporary root leaves
the text before any window is cut from it, and a refusal is cut before the
system's own reason, which one operating system words as a permission and
another as an inappropriate type. The same holds for the math library:
a kernel whose last bit is the library's (`floatCbrt(27.0)` is one bit above
three on glibc) reaches a written expectation only through a relation, and
hostLibraryPrograms prints such kernels in full with the interpreter's
output on the same machine as the only expectation.
