# Execution Result

- **Definition:** Deterministic interpreter completion containing a value and observable output, or a typed runtime failure with source provenance.
- **Not:** An uncaught Haskell exception.
- **Invariant:** Given identical program input and explicit environment, pure Pudu execution is reproducible.
