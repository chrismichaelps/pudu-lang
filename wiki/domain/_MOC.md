# Domain Map

- [[Pudu Language]] — the language product and its governing purpose.
- [[Pudu Program]] — a valid collection of source modules.
- [[Pudu Module]] — compilation and visibility unit.
- [[Source Text]] — immutable user input with stable positions.
- [[Diagnostic]] — stable, actionable compiler feedback.
- [[Pudu Type]] — compile-time classification and guarantees.
- [[Ownership]] — static authority over value lifetime and access.
- [[Core IR]] — checked lowered semantic representation.
- [[Execution Result]] — interpreter outcome.
- [[Compilation Artifact]] — emitted native build result.
- [[Standard Library]] — language-owned foundational APIs.
