# Standard Library

- **Definition:** Versioned foundational modules shipped with [[Pudu Language]] for primitive operations, collections, text, results/options, iteration, IO, time, tasks, and resource scopes.
- **Boundary:** Language semantics define ownership, numeric overflow, iteration protocol, failure propagation, and task lifetime; ordinary algorithms remain library code.
- **Stability:** Public modules follow the language compatibility version and require migration notes for breaking changes.
