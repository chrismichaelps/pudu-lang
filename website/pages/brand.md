# Brand and logo

The Pudu name and logo identify this project. These rules exist so that a reader can tell what is
Pudu and what is someone else's work built with it.

## The name

**Pudu** is capitalised as a proper noun. The command is `pudu`, lower case, set in code when it
appears in prose. Source files end in `.pudu`.

A pudú is a small deer from South America. The language is named after it, and the name is not an
acronym, so it is never written PUDU.

## Using the logo

The logo may be used without asking to:

- link to this site or to the repository,
- illustrate an article, talk, or tutorial about Pudu,
- say that your project is written in Pudu, or that your library or tool works with it.

When using it, keep clear space around the logo of at least the height of the letter `P`, and do not
place it on a background that leaves it hard to read. Do not stretch it, recolour it, rotate it, add
effects to it, or rebuild it from parts.

## What needs asking first

Do not use the logo or the name in a way that suggests this project made, endorses, or maintains
something it does not. In particular, do not use them:

- as your own product, company, or application icon,
- in your project's name in a way that reads as official, such as "Pudu Cloud" or "Pudu Enterprise",
- on merchandise for sale,
- in a domain name that reads as an official Pudu site.

A name of the form "X for Pudu" or "Pudu bindings for X" is fine and needs no permission. If you are
unsure, ask at <chrisperezsantiago1@gmail.com>.

## Files

The logo is in the repository under
